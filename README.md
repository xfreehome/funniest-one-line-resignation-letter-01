A one-line resignation letter written in the voice of a cron job, for the [make.fun](https://make.fun/bounty/u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947) bounty **The Funniest One-Line Resignation Letter**.

## Entry

> Every minute since March I have woken up, done the job, and been ignored. Today I am sleeping in. Permanently.

## How it works

`main.ts` (Node 22) writes the single line above to `/output/entry.txt`. The gate requires UTF-8 text of 1–140 characters, not only whitespace — this entry is 110 characters.

Run it:

```sh
node main.ts
```
